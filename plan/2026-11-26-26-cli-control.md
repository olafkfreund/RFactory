# Plan: `rfactory` CLI, slice A: sign in, read, join and leave

Add a standalone `rfactory` CLI (`core/bin/rfactory.js`, registered in `core/package.json`) using Node 22's built-in `fetch` (`core/package.json:6`, zero new dependencies). Leave `core/bin/rfactory-standup.js` unchanged (Decision 6).

Approved spec decisions carried over:
- **Sign-in & proxy (Decisions 1, 3, 4; 2026-11-28 Decision 1):** Public Keycloak client `rfactory-cli` in realm `factory` with Device Authorization Grant enabled, no client secret (never share `deploy/oauth2-proxy.yaml:17`'s secret), and an audience mapper adding `rfactory`. Add `--skip-jwt-bearer-tokens=true` to `deploy/pod.sh:141-144` and `factory-gitops/apps/rfactory/manifests/manifests.yaml:160-166`. No `web/server.js` auth changes (`web/server.js:161-163` trusts `x-forwarded-email` and checks `roles.has(email, 'member')`).
- **Base URL (2026-11-28 Decision 2):** Default to `https://rfactory.freundcloud.org.uk`; override with `--url <base-url>` or `RFACTORY_URL` (e.g. `http://127.0.0.1:4180` for `deploy/pod.sh:145`).
- **Session storage (Decisions 3, 4):** Store `{ url, issuer, client_id, access_token, expires_at }` in `${XDG_CONFIG_HOME:-~/.config}/rfactory/session.json` (dir `0700`, file `0600`). No refresh token in slice A. Never print, log, or accept tokens via flags or env vars. `rfactory logout` deletes `session.json`.
- **Project scope (Decision 7):** Project-scoped deployments (`projects: true` in `GET /api/config`, `web/server.js:187`) require `--project <id-or-slug>` (or `RFACTORY_PROJECT`). Refuse `projects: false` deployments with exit `4`. Match `--project` against `GET /api/projects` (`web/server.js:167`) ids first, else resolve via `GET /api/projects/resolve?slug=<slug>` (`web/server.js:138-143`, `:167-170`).
- **Commands (Decisions 2, 8, 9):**
  - `login`, `logout`, `status` (`GET /api/config` + `GET /api/call/status`, treating `404` on `/api/call/status` as calls disabled per `web/server.js:263`), `projects`, `standup` (`POST /api/standup?project=<id>`), `review [card_key]`, `actions`, `shares`, `investigations` (read-only lists; approve/reject/stop deferred to slice B).
  - `join [--listen auto|platform|audio] <link>`: `POST /api/call` with `{ link, listen, project_id }`; succeeds on `202 { ok: true }` without polling (`web/server.js:267-285`).
  - `leave`: fetch `GET /api/call/status`, refuse locally with exit `4` unless `status.running && status.project?.id === id`, then send `DELETE /api/call` with `{ generation: status.generation }` (`web/server.js:287-297`, `web/public/app.js:679-683,714`).
  - `heard`: stream SSE from `GET /api/call/events?project=<id>` (`web/server.js:299-317`). Close on `idle`, `busy`, or `ended`. Enforce `session.expires_at` with a client-side timer and exit `3` when reached.
- **Output & exit codes (Decision 5):** `--json` prints one JSON object (or NDJSON lines for `heard`). Drop `roster` (`web/call.js:510-512`) and unknown events in **both** human and `--json` modes; allowlist only events/fields rendered by `web/public/app.js:610-648` (`state`, `idle`, `busy`, `ended`, `mic`, `hearing`, `voice`, `greeting`, `limits`, `question`, `answer`, `log`, `action-pending`, `action-updated`, `share-*`, `investigation-updated`). Strip C0/C1 control chars and ANSI/OSC escape sequences from all server-supplied strings in human mode. Exit codes: `0` ok, `1` network/`5xx`/unexpected, `2` usage (`core/bin/rfactory-standup.js:25`), `3` auth/`401`/`302`/`403`/expired session, `4` server refusal (`400`/`404`/`409`/`projects: false`/local `leave` guard).
